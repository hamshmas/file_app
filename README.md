# 개인회생 신청서 자동 작성 시스템

개인회생 절차에 필요한 서류를 자동으로 생성하는 웹 애플리케이션입니다.

## 주요 기능

### 1. 변제계획안 자동 생성
- **라이프니쯔 현가계수 계산**: 연 5% 할인율 적용 (서울회생법원 기준)
- **현재가치 계산**: 적립기간 + 변제투입기간 고려
- **청산가치 보장 검토**: 현재가치 vs 청산가치 비교
- **재산처분 필요 여부 판단**: 부족분에 대한 재산처분 변제투입예정액 계산

### 2. 수입 및 지출 목록 생성
- **2026년 기준 중위소득 적용**
  - 1인: 2,564,238원
  - 2인: 4,199,292원
  - 3인: 5,359,036원
  - 4인: 6,494,738원
  - 5인: 7,556,719원
  - 6인: 8,555,952원
- **생계비 계산**: 기준 중위소득의 60% (기본), 최대 150%
- **가용소득 계산**: 월수입 - 생계비

### 3. 회생위원 보수 계산
- 급여소득자 + 채무 2억원 이하: 0원 (법원사무관 담당)
- 기타: 가용소득의 1%

### 4. 법원별 기준 분기 처리
지원 법원:
- 서울회생법원
- 부산회생법원 (피부양자 수 계산 특례)
- 대구지방법원
- 대전지방법원
- 전주지방법원
- 청주지방법원

#### 부산회생법원 피부양자 수 계산
- 배우자 소득이 채무자의 70%~130%: 미성년자녀 수의 1/2
- 배우자 소득이 채무자의 70% 미만: 미성년자녀 수 전부
- 배우자 소득이 채무자의 130% 초과: 0명

### 5. 변제예정액표 생성
- 월별 변제일정표
- 적립기간/변제투입기간 구분
- 채권자별 변제금액 배분
- 분기별/연도별 요약

## 핵심 계산 공식

### 라이프니쯔 복리연금현가율
```
현가율 = (1 - (1 + r)^(-n)) / r
```
- r: 월 할인율 (연 5% / 12)
- n: 변제투입기간 (개월)

### 현재가치 계산
```
현재가치 = 월변제액 × (적립기간 + 라이프니쯔현가율)
```

예시 (36개월 변제):
- 적립기간: 3개월
- 변제투입기간: 33개월
- 라이프니쯔 계수: 30.7719
- 총 계수: 33.7719

### 재산처분 변제투입예정액
```
투입예정액 = (청산가치 - 현재가치) × 배수
```
- 1년 내 처분: 1.3배
- 2년 내 처분: 1.5배
